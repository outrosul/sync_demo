# 开发管线 / 角色分工 / DoD

## 七段管线

1. **需求**：明确玩法与同步方式（见 `docs/303_decisions.md`）。
2. **设计**：分层与模块边界（见 `docs/201_architecture.md`）。
3. **逻辑层**：`sync_demo/core/`，可脱离画面测试。
4. **网络层**：`sync_demo/net/`，帧同步 / 状态同步两种分发。
5. **表现层**：pygame 窗口，只读状态。
6. **测试**：`python -m pytest tests/ -q`（逻辑层 + 守卫）。
7. **文档**：改动同轮同步 `docs/`。

## DoD（完成定义）

- 逻辑层有测试且确定性可复现（同 seed 同输入同结果）。
- 两种同步模式都能跑通一次联机。
- 文档与代码同轮一致。
